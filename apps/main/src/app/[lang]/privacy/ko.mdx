## 7. 분석 및 쿠키

- Zoonk가 어떻게 이용되는지 파악하고, 문제를 해결하고, 서비스를 개선하기 위해 PostHog와 Vercel Analytics를 사용합니다. 여기에는 화면이 어떻게 표시되고 사용되었는지 보여 주는 세션 리플레이가 포함됩니다.
- 입력하거나 업로드한 내용이 화면에 있으면 리플레이에 나타날 수 있습니다. 분석 데이터는 Zoonk 운영에 필요한 사람만 볼 수 있습니다.
- 기기의 쿠키와 이와 비슷한 저장 기술은 로그인 상태를 유지하고, 게스트 세션을 보관하고, 언어를 기억하며, PostHog가 방문을 알아보게 합니다.
- 브라우저 설정에서 쿠키를 차단하거나 삭제할 수 있습니다. 모든 쿠키를 차단하면 로그인 상태를 유지할 수 없습니다.

이용자의 브라우저나 앱은 다음 서비스에 직접 정보를 보냅니다.

- **PostHog:** 본 화면, 클릭과 탭, 방문자 ID, 기기, 브라우저, IP 주소, 세션 리플레이. 이용 방식을 파악하고 문제를 해결하기 위해.
- **Vercel Analytics 및 BotID:** 페이지 주소, 이전 페이지, 기기, 브라우저, 보안 검사. 방문 수를 세고 봇을 막기 위해.
- **Sentry:** 오류 세부 정보, 기기, 브라우저. 오류를 고치기 위해.
- **jsDelivr:** 프로그래밍 활동에서의 IP 주소와 브라우저. 프로그래밍 도구를 불러오기 위해.
- **GitHub Pages:** 음악 활동에서의 IP 주소와 브라우저. 악기 소리를 불러오기 위해.
