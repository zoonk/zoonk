# Writing calibration evidence

The held-out unit is a source corpus. A grade uses the normal essay eval generator and its core arithmetic. A saved row keeps the generated score, source mark, model and prompt revisions, frozen key revision for blind grades, input fingerprint, latency, and metered cost. It omits the answer text, prompts, free-text feedback, and quotes. Missing point estimates, incomplete repeats, and keys with mixed row kinds leave the corresponding answers unmeasured. The source marks give whole-answer totals, so a mixed answer cannot tell us which row kind produced an error.

Points are estimated for row kinds measured on at least two sources. “Likely” targets a correct call at least four times in five, using the 80th percentile of measured error in each direction to widen an answer's estimate before comparing with a minimum.

## Sources

- **ELLIPSE.** Crossley et al., *Measuring second language proficiency using the English Language Learner Insight, Proficiency and Skills Evaluation (ELLIPSE) Corpus* (2023). The [pinned corpus and rating rubric](https://github.com/scrosseye/ELLIPSE-Corpus/tree/710963bbf1acf23a28e40643d9f937d06f047dd4) are released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The sample retains IDs, topic labels, responses and the six human-rated analytic marks. It paraphrases the six published analytic scales and compares the equal-weight mean of their marks.
- **ASAP 2.0.** Crossley et al., [ASAP 2.0 corpus](https://github.com/scrosseye/ASAP_2.0/tree/060ab225ca0984c0bf43ff222bf6bb2bc6195b6f), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The sample uses the public test archive. Source passages carry separate reprint notices, so the fixtures keep file references. It retains assignments, responses and human marks, loads text extracted from the accompanying source PDFs at run time, and uses a paraphrase of the published holistic rubric.
- **SAF legal German.** Filighera et al., [Short Answer Feedback legal-domain German corpus](https://huggingface.co/datasets/Short-Answer-Feedback/saf_legal_domain_german), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The sample uses the four corpus questions whose selected references give explicit additive item weights. It retains question and answer text, anonymous answer IDs and expert scores. The board-key cases paraphrase those weighted reference items. The blind writer sees only the question and the one-point task maximum.
- **Enem.** The [pinned research dataset](https://huggingface.co/datasets/laisnuto/self-collected-ENEM-dataset/tree/1062474) has no license displayed. The added cases retain row numbers and marks and load answers at run time from that revision. The [Inep handbook](https://download.inep.gov.br/publicacoes/institucionais/avaliacoes_e_exames_da_educacao_basica/a_redacao_no_enem_2025_cartilha_do_participante.pdf) supplies the five competence scales. Theme labels come from the [Inep exam archive](https://www.gov.br/inep/pt-br/areas-de-atuacao/avaliacao-e-exames-educacionais/enem/provas-e-gabaritos).
- **FGV OAB and CACD.** The existing cases and their source citations are in the [grade-essay fixtures](../../src/tasks/grade-essay/cases). The blind keys use the question and the grading rules candidates could see.

The samples omit demographic columns. The report checks each run against the source's cutoff, using 60% as an analysis cutoff for sources without a minimum. It shows the share of runs called above or below the cutoff and the share of each call that was wrong. OAB and CACD apply their official percentages to aggregate exam marks.

## Reproduce

From `apps/evals`, run TypeScript scripts using `node --conditions=react-server --import tsx --import ./scripts/register-markdown.mts`. The paid runner also needs the usual eval environment. Freeze keys with `scripts/write-blind-keys.ts --draw <1|2|3>` and explicit question IDs. Run `scripts/run-writing-calibration.ts <source> <output.jsonl> <forecast-usd-per-call> <allocation-usd>` for each source. For `asap`, set `WRITING_CALIBRATION_ASAP_SOURCES` to a local JSON object keyed by the accompanying PDF filenames, with each value containing the transcribed article. Use `saf-board` for the published SAF key and `saf` for its blind keys. The runner resumes an existing output file using completed input/run fingerprints. Set `WRITING_CALIBRATION_MEASURABLE_ONLY=1` to limit a budgeted run to answers whose available keys use the intended kind throughout. Run `scripts/written-calibration.ts` to print the held-out table and write the core calibration from saved runs without making model calls. Repeat the measurement every six months.
