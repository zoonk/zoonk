# Step contract

`Step.content` and `StepVariant.content` follow this contract. `Step.kind` picks the content schema and `Step.contractVersion` stores `STEP_CONTRACT_VERSION` (1). Import it from `@zoonk/core/library/steps/contract`.

## Kinds

| Kind            | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hook`          | `variant: "guess"` (question, options with one `isCorrect`, `reveal`) or `variant: "text"` (rich text). The guess never counts.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `explanation`   | Rich `text`, optional `title`, optional `image` request, optional `exampleLineSlot: { idea }` where the personal layer may add one sentence about the learner's life.                                                                                                                                                                                                                                                                                                                                                                             |
| `workedExample` | `problem`, 2 to 8 `steps` (`text`, optional LaTeX `math`) the player reveals one at a time, and `result`.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `check`         | Multiple choice: `question`, optional `context`, options with exactly one `isCorrect` and a `reason` on every option.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `typedAnswer`   | `question`, `keyPoints` (graded later), `sampleAnswer`, optional `acceptedAnswers` matched by code.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `spokenAnswer`  | `prompt`, `targetText`, `language`, optional `translation` and `romanization`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `summary`       | `ideas`: each idea of the lesson in one sentence.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `activity`      | An interactive activity: `{ template, prompt, fields, check, data? }` (see `../../activities/README.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `challenge`     | A multi-step case solved like at work (`variant: "work"`) or a light "What if" (`"whatIf"`): `title`, `setting`, `mission`, optional `deadline`, data `panels`, `team` slots by role (one may be `ai`), `meters`, a decision graph (`startNodeId`, `nodes` with `messages` and 2 to 4 `choices`, each with `quality`, `replies`, meter `effects`, an optional `timeJump` and debrief `notes` per skill), `endings` and `skills` with a practice line. Code checks the graph (`getChallengeGraphIssues` in `../../challenges/challenge-graph.ts`). |
| Language kinds  | `fillBlank`, `matchColumns`, `multipleChoice` and `alphabet` (`language-exercises.ts`). `vocabulary`, `reading`, `listening` and `translation` are `{}`: their word or sentence comes from `Step.wordId` or `Step.sentenceId`.                                                                                                                                                                                                                                                                                                                    |

Rich text is Markdown limited to emphasis, lists, GFM pipe tables of data, inline code and `$...$` LaTeX. A step asks for at most one image with `image: { prompt, alt }`; the generated file is linked through `Step.mediaAssetId`, never stored as a URL in the JSON. Hooks, explanations, worked examples, checks and typed answers may carry a `visual`: a bar or line chart (`categories` and up to three `series` of values) or a timeline (dated `events`), the shape in `@zoonk/ai/tasks/v2/visuals/schema`, which the player draws from data. A screen whose words point at something to see (a picture, a table, a chart, a timeline) shows it: code checks that (`library/quality/_utils/visual-references.ts`). Text fields have length limits in the schemas, so the model sees them too.

## Reading and writing

- `stepContentSchemas[kind]`: the zod schema for one kind, for AI output or API docs.
- `safeParseStepContent(kind, content)`: zod's result, for generation loops.
- `parseStepContent(kind, content)`: typed content, throws on invalid data. Use it when reading stored steps.

Every parse first repairs generated JSON (malformed `\u00005c` escapes and NUL characters), so repaired content can be stored in Postgres.

## Changing the contract

Adding an optional field is backwards compatible. Anything else bumps `STEP_CONTRACT_VERSION` and needs a migration of stored steps, because readers throw on content they can't parse.
