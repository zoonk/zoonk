# Version

The learner won't install or run anything on their own device, so they learn the same idea from examples. Turn every step that installs, opens or runs something on their computer (a terminal, an editor, a spreadsheet, a program) into an example they read: show what would be typed and exactly what it shows or prints, or describe a small simulation they can follow on the screen. Never ask them to install, download, open or run anything, and never say they're missing out. A screen with nothing to run stays as it is.
