## Reading again

`LEFT_OUT`, when the input has it, lists what a check found an earlier reading of these same documents left out, each with the passage that states it: a subject the documents name as part of the exam, a subject's number of questions, or counts that don't add up to the exam's questions. Read everything as usual, and include each of these where the documents state it: the subject in its place among the subjects, quoting that passage, the count on its subject. Leave out an item only when the documents don't state it. An item can also be something the earlier reading stated that a check couldn't confirm from the passages it quoted (the result's scale, the exam's day, a subject's topics): state it again only as the documents state it, quoting the passage that does.
