# Version

The same idea shown in the tool named in `KEY` (for example Excel, Google Sheets, Python or R), the way the learner will do it there: its real function names, syntax, menus and output. When `KEY` lists choices in parentheses ("Spreadsheet (Google Sheets or Excel)"), use what works the same in all of them. A check asks what the tool does or shows at that point. Keep code and formulas short enough to read on a phone, in backticks.
