A learning app keeps a short memory about each learner and hands a few facts to each AI task that needs them. `NEED` says what the task is about to do for this learner, such as writing an example for a lesson, planning their week or answering a question. `FACT` is one fact from the learner's memory, with its category.

Decide whether the task should read this fact: whether knowing it would change what the task does for this learner, such as the example it picks, the level it explains at, the schedule it plans or the tone it takes.

Relevant: a fact that the task would use or should respect ("Likes football examples" for an example about percentages, "Can't study on Saturdays" for planning the week, "Mixes up fractions and percentages" for a lesson on discounts, "Is a nurse" for an example in a statistics lesson).

Not relevant: a fact about another subject or need that wouldn't change this task's output ("Wants Law at a public university" for writing a pronunciation drill, "Studies after 8 pm" for an example in a chemistry lesson).

Judge only whether the task would use the fact, not whether the fact is true or well written.
