- When writing a prompt, don't use "Zoonk" (eg "You're a Zoonk tutor"). Models don't know what "Zoonk" is, and it can lead to confusion or irrelevant responses. Instead, you could use something like "You're a tutor for a learning app."
- Prompts that write learner-facing copy must never promise a pass, score, admission, certificate or job. Use "preparation" language and, for exams, an estimated score only as a range after a mock (see `packages/i18n/.eloqnt/styleguide.md`, "Honest progress").
- Every task runs its model call through `runTaskGeneration` (`startTaskGeneration` for streams, in `src/provenance/`) and returns its `provenance`: the model that actually ran (a fallback when the requested model failed, read from AI Gateway routing metadata, not `response.modelId`), prompt version, usage, cost and latency. That also sends one `$ai_generation` event. Tasks accept an optional `analytics` context; callers pass the learner id, goal and content scope so cost can be summed per learner.
