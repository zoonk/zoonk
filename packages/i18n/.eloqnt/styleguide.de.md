# `de` styleguide

- Use an informal, approachable register. Address the user as "du".
- Use standard German spelling and grammar.

## Special Cases

- Treat "Brain Power" as a product-like term. Do not add German articles before it in headings or short labels.
- For belt colors, use masculine forms. For example, "White Belt" = "Weißer Gürtel", "Yellow Belt" = "Gelber Gürtel", etc. If it's color alone in the context of belts, use "Yellow" = "Gelb", "White" = "Weiß", etc.
- For "thinking messages", keep this in mind: Infinitives as loading states feel static and impersonal in German. English "-ing" naturally implies ongoing action; German infinitives don't carry that.
- Study cards are "Lernkarten", never "Spielkarten".
- Short durations keep the source's "~~" and abbreviate the unit with a period: "~~{minutes} min" = "~~{minutes} Min.", "~~{hours} h" = "~{hours} Std.", "{minutes} min" = "{minutes} Min.".
- Use Germany's context for examples and exam names, such as the "Abitur", instead of US ones like the SAT. For example, "pass the SAT in March" = "im März das Abitur bestehen".
- Statements in exams where a wrong answer cancels a right one are judged right or wrong, not true or false: "{judgment, select, right {Right} other {Wrong}}" = "{judgment, select, right {Richtig} other {Falsch}}". Other uses of "right" and "wrong" keep their usual translations.
